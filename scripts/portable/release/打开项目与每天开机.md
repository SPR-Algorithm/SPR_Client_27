# 打开项目与每天开机

## 没有路由器时，看自定义客户端

**Windows x64** 上，完整解压项目后双击 `02-运行脚本/Windows/8-启动Windows自定义客户端.bat`，或者直接双击 `04-自定义客户端/Windows/RoboMasterClient2025.exe`。运行库随程序一起放在 Windows 目录。程序打开后没有比赛数据和图传时，可查看离线界面。退出可按 **Alt+F4**。

按 **P** 打开设置，选赛项与车位，再用现场本地配置连接对应赛事端。主图传由选手端转发到 UDP 3334。断网时仍可打开客户端，服务可达后会重试。

赛项配置与验收方法见 [2027 客户端联调说明](RM2027客户端联调说明.md)。

### Linux 手动启动

在已编译过客户端的 **Linux NUC 或 Linux 虚拟机桌面**上，打开项目的 `02-运行脚本/Linux`，右键空白处选“在终端打开”，运行

```bash
bash ./6-启动Linux自定义客户端.sh --foreground
```

没有赛事端时界面显示离线。想看带演示数据的战术屏，可以关闭客户端后运行

```bash
RM_START_VIEW=tactical RM_TACTICAL_MOCK=1 bash ./6-启动Linux自定义客户端.sh --foreground
```

也可以手动进入 `04-自定义客户端/源码/build-portable`，执行 `./RoboMasterClient2025`。如果系统提示缺 Qt 动态库，使用上面的 6 号脚本，它会加载构建时使用的 Qt。已经装好旧版的设备也可从原来编译好的目录启动。新装 Linux 第一次需要先用 5 号脚本联网编译。关闭预览可用 **Alt+F4**。

## 在 Windows 手动打开官方软件

- 双击 `03-官方程序/01-引擎/RoboMasterEngine.exe` 打开服务器和裁判端。
- 双击 `03-官方程序/02-选手端/start.bat` 打开官方选手端和辅助进程。
- 想一次打开两者，运行 `02-运行脚本/Windows/2-启动Windows官方端.bat`。软件打开后按需在官方界面登录。

## 接设备联调

1. 图传接收端、机器人、路由器、Windows 主机和 Linux NUC 按平时方式接好并开机。
2. Windows 连上比赛路由器的 WiFi 或比赛网线；需要引擎外网登录时，保留手机共享等上网连接。
3. Windows 比赛地址已配置好，直接手动开官方软件或双击 **2-启动Windows官方端.bat**。确实需要设置比赛地址时，先运行 **6-只配置比赛网络.bat**。
4. 在官方软件中完成 DJI 登录和机器人身份选择。
5. NUC 登录图形桌面，打开 `02-运行脚本/Linux`，运行 **6-启动Linux自定义客户端.sh**。三处机器人身份保持一致。

## 只有首次换新电脑时

- Windows 运行脚本 **1**：先检测，已安装的跳过，只补缺少的运行时或图传驱动。
- Linux 运行脚本 **5**：联网安装并编译自定义客户端，完成后再用 **6**。

## 收工

- NUC 运行脚本 **7** 停止自定义客户端。
- 官方程序可以各自关掉。如果用过 Windows **6** 配置网络，可运行 **3** 关闭本套官方程序并还原网络。
