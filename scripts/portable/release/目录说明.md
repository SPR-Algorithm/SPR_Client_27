# 目录说明

整个项目保留在同一层目录。双击根目录的《打开项目.txt》查看入口，复制或移动时保留整套目录。

| 目录 | 放什么 | 什么时候打开 |
|---|---|---|
| `01-文档` | 使用步骤、官方 PDF、目录说明和验证记录 | 查操作步骤时 |
| `02-运行脚本/Windows` | 安装、启动、还原、诊断脚本；`internal` 是内部脚本实现 | Windows 每次使用 |
| `02-运行脚本/Linux` | 首次安装、启动、停止脚本 | NUC 或 Linux 虚拟机使用 |
| `03-官方程序` | 官方服务器/裁判端、官方选手端、RoboMaster Tool 2 完整软件包 | 脚本自动调用 |
| `04-自定义客户端/源码` | 自定义客户端完整源码、资源、测试和开发资料 | 开发或 Linux 编译时 |
| `04-自定义客户端/Windows` | Windows x64 自定义客户端和随包运行库 | Windows 可直接打开其中的 EXE，也可用 8 号脚本 |
| `05-安装包/Windows` | .NET 7、VC++ 运行库、DJI 驱动官方安装器 | 脚本 1 先检测，只打开缺项的安装器 |
| `05-安装包/Linux` | 老 Ubuntu 所需 Protobuf 源码归档及校验文件 | 首次编译时自动使用 |
| `06-配置/Windows` | `settings.json` 网络参数和安装包校验值 | 改网卡或接线模式时 |
| `06-配置/Linux` | 首次编译使用的客户端配置模板 | 首次安装前选身份和 MQTT 地址 |
| `07-校验清单` | 打包文件清单、官方核心程序 SHA-256 | 交付或排查文件损坏时 |

开发电脑的 `08-交付与归档` 存放发送给队友的 ZIP 与历史文件。解压包中只包含使用和开发所需目录。

`01-文档` 只放文档，`02-运行脚本` 只放脚本。普通使用者从这两个目录进入即可。

官方软件包内部的 `ReadMe`、`StreamingAssets`、`Tools`、DLL 和安装器随官方原有结构保留；不要拆开移动。自定义源码内部的 `docs`、`scripts`、`resources` 等遵循原工程布局，便于正常构建和继续开发。

本机从 `04-自定义客户端/源码` 打开 Git 或 IDE。打包时使用其中的 `scripts/portable/package.py`。

首次 Linux 编译后，程序与实际运行配置生成在 `04-自定义客户端/源码/build-portable/`，其中 `config.json` 是运行配置。后续换机器人、改 MQTT 地址应修改这份运行配置，`06-配置/Linux/config.example.json` 是首次安装模板。

运行日志与网络备份保存在各自电脑：Windows 为 `%LOCALAPPDATA%\SPR-RM26`；Linux 为 `~/.local/state/rm26-client`。另一台电脑的网络备份不会随发行包传递。
