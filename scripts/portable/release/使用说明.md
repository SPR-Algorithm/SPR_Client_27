# SPR 项目使用说明

先把压缩包完整解压，保留整个 `SPR_RM26` 文件夹。可以放在其它盘符、用户名或含中文和空格的路径下；不要在压缩包预览里启动，也不要单独复制 BAT 或 EXE。

只想看自定义客户端时，Windows x64 双击 8 号脚本，Linux 桌面运行 6 号脚本。离线预览和手动打开路径见《打开项目与每天开机.md》。

## Windows 主机

日常入口都在 `02-运行脚本/Windows`。

**8-启动Windows自定义客户端.bat** 打开便携的自定义客户端。它和官方软件独立启动。官方端使用下面的 1、2 等脚本。

1. 新电脑首次双击 `1-首次安装Windows依赖.bat`。它先检测 .NET 7 x64、Visual C++ x64 **运行库**和 DJI 图传 USB 驱动，已装好的自动跳过，只打开缺少项目的官方安装器。三项齐全时直接结束，不弹安装界面或管理员提示。这里没有 Visual Studio 开发软件。.NET 8/9 不能代替 .NET 7；兼容的较新 VC++ 运行库可以沿用。安装器若要求重启，请保存工作后重启。
2. 双击 `2-启动Windows官方端.bat`，打开官方引擎和选手端。两者也可分别双击 `03-官方程序/01-引擎/RoboMasterEngine.exe` 和 `03-官方程序/02-选手端/start.bat`。
3. 接设备联调时连上比赛路由器，按需保留一条外网连接供引擎登录。若需要设置 Windows 的比赛地址，运行 `6-只配置比赛网络.bat`。脚本识别比赛 WiFi 或目标网段，备份连接参数后应用配置。
4. 完成引擎测试、DJI 账号登录。官方选手端按 **P** 选择机器人并登录，与机器人主控和自定义客户端保持一致。
5. 收工双击 `3-关闭并还原Windows网络.bat`，关闭本套官方程序，恢复启动前的 IP、DNS、网关、跃点数和临时防火墙规则。
6. 排障时双击 `4-诊断Windows环境.bat`。

Windows **2** 和 Linux **6** 各自启动软件。已经配好比赛网络时，硬件接好即可启动。

其它入口：`5` 只关闭官方程序，`6` 只配置比赛网络，`7` 是没有备份时，将自动识别到的比赛连接恢复 DHCP 的应急入口。原本需要静态 IP 的网络不要随意使用 `7`。

Windows 网络配置参数在 `06-配置/Windows/settings.json`。`AdapterName` 留空时，网络配置脚本会自动检测。更换路由器名称、比赛网段或改用双网卡直连时，可在此调整。网络备份和操作日志保存在当前电脑 `%LOCALAPPDATA%\SPR-RM26`。

## Linux NUC 或虚拟机

入口都在 `02-运行脚本/Linux`。首次安装支持 **Ubuntu 22.04/24.04 x86_64**，需要联网和 sudo；Qt 会联网下载，本包提供自定义源码和自动构建脚本。

1. 完整解压到 Linux，登录图形桌面。
2. 首次安装前可改 `06-配置/Linux/config.example.json`，默认 2027 超级对抗赛、红方 3 号。使用随包的 RM26 官方程序时，按 P 切换到 2026 联调。
3. 在普通桌面用户的终端运行 `bash ./5-首次安装Linux客户端.sh`。安装依赖并编译到 `04-自定义客户端/源码/build-portable`，不覆盖旧 `build`。
4. 完成后运行 `bash ./6-启动Linux自定义客户端.sh`。文件管理器支持脚本执行时，也可选“在终端运行”。
5. 停止运行 `bash ./7-停止Linux自定义客户端.sh`。启动脚本支持 `--restart`、`--status` 和 `--check`。

Linux **实际运行配置**在 `04-自定义客户端/源码/build-portable/config.json`。首次安装模板只用于初始化，后续改身份或地址要改实际配置。机器人红方 ID 为 1–7，蓝方为 101–107；英雄红方 1 号设 `client_robot_id: 1`，同时在官方端和主控选择相同机器人。

日志在 `~/.local/state/rm26-client/client.log`，首次安装日志在源码目录 `.dependencies/install.log`。SSH 启动使用与图形桌面相同的 Linux 用户，启动器不保存 SSH 密码。

## 网络和图传

使用共享局域网联调时，在 Windows 本地配置填写比赛网卡地址，Linux 端填写赛事端 MQTT 地址。换机前还原或断开旧电脑的比赛网卡。

使用官方手册的直连接法时，分别设置接引擎和接自定义终端的有线网卡。填写 `ClientAdapterName` 和 `ClientSubnet`，并按现场分配设置终端地址。隔离网卡留空默认网关。

官方选手端先正常显示图传，才具备向自定义客户端转发的前提。自定义客户端接收 UDP **3334** 主图传；右下角“工业相机预览”是另一条自定义通道，无推流时可以为空。MQTT 连接成功不能单独证明图传已转发到正确 IP。

操作：**Ctrl+T** 切主图传/战术屏；**M** 切战术大地图；按住 **F12** 看帮助；**H** 打开兑换；战报点“关闭战报 (Esc)”或按 **Esc**。新版启动器默认进入主图传。

## 维护

维护源码在 `04-自定义客户端/源码/scripts/portable`。`02-运行脚本` 是交付入口，`internal` 中的 PowerShell 由打包工具生成；修改维护源码后应重新打包同步。

目录归属见《目录说明.md》，官方 PDF 在《官方手册》子目录，验证范围见《优化与验证记录.md》。账号登录、接线、硬件对频由操作者完成。Linux 首次整机安装与比赛链路仍需在目标设备上验证。
