# SPR 运行包与脚本

本目录保存 Windows 和 Linux 的启动及打包工具。从 GitHub 下载源码后，按[客户端使用指南](../../docs/getting-started/user-guide.md)安装依赖、构建并启动。完整联调用的官方选手端、引擎和驱动应从官方渠道取得。

## 现有本地运行包

以下入口随战队完整运行包交付。

- Windows 自定义客户端从 `02-运行脚本/Windows/8-启动Windows自定义客户端.bat` 打开，可离线查看界面。
- 首次运行官方选手端时执行 Windows 依赖检查，缺项按官方随包说明安装。比赛地址设置与启动程序各有独立入口。
- 联调结束时用 Windows 的还原脚本恢复此前保存的网卡配置。按现场网络填写本地配置，保留正常上网使用的默认路由。
- Linux 使用 `linux/install-client.sh` 和 `linux/rm26-client.sh`。先按交付包的说明配置运行目录及裁判链路。

## 更新已有的本地交付目录

`deploy.ps1` 和 `package.py` 可在既有编号交付目录布局中使用。该布局将独立源码放在 `04-自定义客户端/源码`，Qt 运行文件放在 `04-自定义客户端/Windows`。先读交付目录的《打开项目.txt》，再在其中的源码目录执行工具。新生成的 Windows 示例网络地址专用于文档，请在联调前填入现场地址。

标准 Git 工作区以[根目录 README](../../README.md)为入口。独立构建请使用外部 SDK 路径及自己的 `build/` 目录。
