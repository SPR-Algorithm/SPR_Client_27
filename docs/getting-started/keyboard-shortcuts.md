# 客户端快捷键

## 比赛中常用

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+T` | 在操作手的全屏主图传和战术指挥屏之间切换。两页共用顶部比赛栏，保留比分、倒计时、领先依据和赛项支持的基地与前哨血条。 |
| `Ctrl+Y` | 在战术指挥屏切换地图优先和工业相机优先。工业相机优先时，右侧继续显示地图。 |
| 按住 `Tab` | 查看全屏战况，松开返回原画面。超抗显示双方基地和前哨，联盟赛同时显示场地图。2026 兼容模式沿用原统计面板。 |
| `M` | 打开或收起大地图。操作手大地图内使用 `A` 切换攻击标记、`B` 切换警戒标记、`I` 切换防御标记。 |
| `P` | 打开或关闭设置。也可以用 `+`、`-`、`*`、`/` 打开或关闭。 |
| 按住 `~` | 查看伤害统计，松开关闭。使用数字键 1 左侧的键。 |
| `Esc` | 收起正在显示的全屏战况或结算页。 |
| 按住 `F12` | 查看快捷键提示，松开关闭。 |

## 在设置中选车

先用 `P` 打开设置，选择赛项，再选择车位。使用数字键选车后，按 `Enter` 确认。赛项决定可选范围，哨兵等未分配数字键的车位可以在设置里点击选择。

| 阵营 | 数字键 → 机器人 ID |
| --- | --- |
| 红方 | `1` → 1，`2` → 2，`3` → 3，`4` → 4，`5` → 6 |
| 蓝方 | `6` → 101，`7` → 102，`8` → 103，`9` → 104，`0` → 106 |

例如，1V1 用 `3` 选红方步兵，用 `8` 选蓝方步兵。

## 操作手界面

角色专属交互以当前面板和裁判系统下发的可用状态为准。

| 快捷键 | 功能 |
| --- | --- |
| `O` / `I` | 在主图传操作界面打开或关闭 17mm / 42mm 弹丸补给面板。离线可查看，确认兑换须有裁判系统许可。大地图展开时，`I` 选择防御标记。 |
| `H` | 登录车位后，在主图传操作界面打开或关闭该车位的兑换、工程装配或空中支援面板。普通远程兑换需要裁判系统开放远程回血或补给中的至少一项。 |
| `Ctrl+G` | 切换操作手的自定义数据叠加层。 |
| `Ctrl+L` | 刷新工业相机画面。 |
| `Y` / `F1` | 裁判系统允许时，确认免费复活 / 付费立即复活。 |
| `Ctrl+1` / `Ctrl+2` / `Ctrl+3` | 兑换面板内选择回血 / 17mm / 42mm 兑换项，随后用 `Y` / `N` 确认或取消。 |
| `1` 到 `4`、`Enter`、`Y`、`L` | 工程装配面板内选择难度、确认选择、确认当前步骤、退出当前操作。 |
| 长按 `K` / `L` | 英雄部署模式面板内进入或退出部署。 |
| 长按 `F` | 步兵在能量机关面板可用时发起激活交互。 |
| `Ctrl+1` / `Ctrl+2` / `N` | 空中支援面板内申请免费支援 / 付费支援 / 中断支援。 |
| `J`、`F`、`Y` / `N`、`L` | 飞镖面板可用时切换目标、打开闸门确认、确认或取消、请求发射。 |

登录后，操作手界面可发送键鼠数据。实际控制来源由选手端设置决定，具体动作的按键绑定由车端程序决定。打开全屏战况会暂停键鼠转发，松开 `Tab` 后可继续操作。

## 本地联调

`Ctrl+R`、`Ctrl+J`、`Ctrl+F` 在操作手界面用于模拟结算、热量和弹量。`Ctrl+Shift+F8` 和 `Ctrl+Shift+F9` 用于检查定时事件和事件提示弹窗。联调键会产生测试画面，应在本地测试时使用。
